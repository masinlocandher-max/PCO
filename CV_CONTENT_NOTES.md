# Francine Marie Bautista — One-Page CV Content Scope

This branch defines the public CV as one continuous, scroll-driven website experience at the canonical root.

## Required visitor flow

1. Purpose gate: Curriculum Vitae or FMB News.
2. CV choice opens the optional music gate.
3. CV opens directly to Francine Marie Bautista's full name, professional designation and brief introduction.
4. The full CV continues on the same page through professional profile, career experience, education, expertise, service, communication/presence, creative practice, founder-led initiatives, selected work, culture/community work, professional value and consultation calendar.
5. The calendar is the closing professional action point.
